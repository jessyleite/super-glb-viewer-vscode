## Project Overview

Super GLB Viewer is a VS Code extension that provides a custom editor for viewing GLB/GLTF 3D model files directly in VS Code. It uses the `super-glb-viewer` library (a React-based 3D viewer) rendered in a webview.

## Build Commands

```bash
npm run compile    # Compile TypeScript to out/
npm run watch      # Watch mode for development
npm run package    # Create .vsix package for distribution
```

## Architecture

- **src/extension.ts** - Extension entry point, registers the custom editor provider
- **src/glbEditorProvider.ts** - Custom editor implementation using `CustomReadonlyEditorProvider`
- **media/** - Contains the bundled `super-glb-viewer` library assets (JS, CSS) and static resources (vendor files, HDR environments)
- **out/** - Compiled JavaScript output (generated by `tsc`)

## Webview Resource Handling

The extension uses VS Code webviews which have strict security constraints:

1. **localResourceRoots** - Must whitelist folders the webview can access (currently `media/`)
2. **asWebviewUri()** - Convert local paths to webview-accessible URIs
3. **CSP** - Content Security Policy is configured in the HTML template
4. **window.__PUBLIC_BASE_URI__** - Global variable injected into webview for the library to load dynamic assets (vendor WASM files, HDR textures)

When adding new static assets that the viewer library needs to load dynamically, ensure the containing folder is in `localResourceRoots`.

## Development

To test the extension:
1. Run `npm run compile`
2. Press F5 in VS Code to launch Extension Development Host
3. Open a `.glb` or `.gltf` file

The GLB file content is read and converted to a base64 data URL before being passed to the React viewer component.
